# Tests selected by `pytest -m referee`: a subset a referee can run on a CPU-only machine in a
# couple of minutes. tests/conftest.py adds the "referee" marker to every test collected under
# one of the node ids below; a file selects all its tests, "file::test" selects every
# parametrization of a test, and a full node id (with [...]) selects one. Blank lines and lines
# starting with # are ignored. A listed file whose tests are collected but that matches nothing
# stops the run, so a renamed test cannot drop out silently.
#
# Tests that need an optional reference package skip when it is missing: MONAI, MedPy, SimpleITK,
# DeepMind's surface-distance, MeshMetrics and VTK (see the user manual for how to install them).

# Exact Euclidean distance transform: SciPy and brute-force oracles, the exact floating-point
# minimum (property test), the adversarial lines of the exactness proof (far and near ties),
# extreme spacings and the overflow guard.

# Correctly rounded sums, and surface means that do not depend on threads or devices.
